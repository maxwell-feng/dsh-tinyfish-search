# 发行说明 — v0.12.0

[英文](RELEASE.md) | 中文

发行日期：2026-09-24

**dsh-tinyfish-search** 0.12.0 完成与 DeepSeek Harness 0.1.7-rc.2 的对齐。本版不改运行时逻辑、不改配置、不改工具接口，行为与 0.11.1 完全一致。

## 变更

- **宿主对齐**：开发依赖升级到 DeepSeek Harness 0.1.7-rc.2，并已针对该版本完成验证。
- **peer 区间不变**：仍为 ^0.1.7-alpha.2，即引入易变配置的那条发布线，因此插件在 0.1.7-alpha.2 至 0.1.7-rc.2 的每一个预发行版上仍可安装。宿主引擎区间与 Node 引擎区间均未改动。
- **接缝核对**：本插件使用的全部接口在 rc.1 与 rc.2 源码中完全一致——web 搜索提供方接缝、凭据解析、Host 读取的易变配置 schema，以及启动环境查询。
- **源码改动**：插件源码只有一处变动，即 `USER_AGENT` 版本常量。
- **供应链闸门**：工作区文件现对 rc.2 的各包豁免 pnpm 的最小发布年龄闸门，否则 DSH 持续发布的预发行版会被拦下。
- **文档**：安装、更新、配置、使用、卸载五份指南的中英双语版本均已更新为 0.12.0 的版本横幅与命令。

## 修复

- **行尾**：仓库原先没有 `.gitattributes`，Windows 检出会把部分文档写回 CRLF，另一部分仍是 LF。现全部固定为 LF，与姊妹仓库 dsh-kingdee 一致。
- **旧版更新日志**：中文侧有八个版本重复了分类标签，一个版本正文只剩一行，一条安全条目丢失了 CVE 编号；英文侧有一个版本写错了 user-agent 取值。均已修正。

## 升级

执行 `dsh plugin --profile web add dsh-tinyfish-search@0.12.0`，或让 profile 跟踪最新发行版即可。无需任何手工步骤，完整历史见 CHANGELOG.zh.md。

## 验证

- 类型检查与构建均干净，22 项单元测试在 DeepSeek Harness 0.1.7-rc.2 上全部通过。
- 冻结锁文件安装通过 pnpm 的供应链策略校验。
- 声明的 peer 依赖经宿主自带的兼容性校验在 rc.2、rc.1、alpha.2 上均准入，无需豁免；0.1.6 宿主会被拒绝，与安装、更新文档一致。
- 实际打包的 0.12.0 压缩包可装入真实的 0.1.7-rc.2 profile，并组合出 dsh-tinyfish-search 图层，同时覆盖 web 与 tool-web 两行。
